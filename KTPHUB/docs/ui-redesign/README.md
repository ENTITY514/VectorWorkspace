# Пересмотр UI (UI Redesign)

> Отдельный трек развития редактора КТП. Статус: предложение.
> Для каждого пункта: **Задача → Метод решения → Что решает → Метрики качества**.

## D1. Тёмная тема

- **Задача.** Переключатель темы (светлая / тёмная / системная) для всего редактора КТП.
- **Метод решения.**
  1. Подключить тему на базе MUI `createTheme`/`ThemeProvider` с двумя палитрами.
  2. Переключатель: «светлая / тёмная / как в системе»; сохранять выбор (`localStorage`/настройки профиля).
  3. Прогнать текущие захардкоженные цвета строк (`getBackgroundColor` в `KTPTableRow`, цвет плашек/четвертей) через `theme.palette`, чтобы в тёмной теме не осталось «светлых» блоков.
  4. Проверить контраст текста/фона в обеих темах.
- **Что решает.** Комфорт при длительной работе, доступность.
- **Метрики качества.**
  - Переключение темы применяется мгновенно и без перезагрузки.
  - Выбор сохраняется между сессиями.
  - Нет «слепых» зон (захардкоженный белый фон в тёмной теме); контраст ≥ WCAG AA для основного текста.

## D2. Настройка таблицы (скрытие колонок, закрепление шапки и первой колонки)

- **Задача.** Возможность скрывать колонки, закреплять шапку и первую колонку при прокрутке.
- **Метод решения.**
  1. Панель видимости колонок (чекбоксы: №, Часы, Раздел, Тема, Цели, Кол-во часов, Дата, Примечание, Действия); сохранять настройки.
  2. Закрепить шапку (`stickyHeader` уже есть — оставить/улучшить) и первую значимую колонку (№/тема) через `position: sticky`.
  3. Учесть объединённые строки (quarter-header, плашки) при горизонтальной прокрутке.
- **Что решает.** Гибкий вид таблицы под конкретную задачу, удобство на длинных планах.
- **Метрики качества.**
  - Скрытие колонки не ломает DnD и редактирование.
  - Настройки видимости сохраняются.
  - Шапка и первая колонка остаются видимыми при вертикальной/горизонтальной прокрутке.
