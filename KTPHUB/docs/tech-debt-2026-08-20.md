# Техдолг: 1–4 классы — без СОР и СОЧ (A13)

> Статус: техдолг (отложено) · Дата: 20.08.2026
> Вынесено из `KTPHUB/docs/ktp-editor-plan.md` (пункт A13) по решению ревью 20.08.2026.

## Задача

По новому закону в 1–4 классах СОР и СОЧ отменены. Перед генерацией КТП нужен
пункт «Добавить СОР и СОЧ» и плашка об отмене для 1–4 классов.

## Критерии (когда возьмём в работу)

- Перед генерацией КТП из ТУП — переключатель/чекбокс «Добавить СОР и СОЧ».
- Если класс 1–4 — плашка «СОР и СОЧ отменены для 1–4 классов», СОР/СОЧ не добавляются.
- Для 5+ классов — текущее поведение (добавлять по умолчанию/по флагу).

## Метрики качества

- Для grade 1–4 СОР/СОЧ не генерируются, плашка отображается.
- Для grade 5+ поведение без изменений (тест).

## Примечание по данным

Модель ТУП в KTPHUB (`StoredTup`/`AcademicPlan`) не содержит поля `grade`.
При реализации нужно решить, откуда брать класс: из названия ТУП, новое поле в
загрузке, или поле «класс» на шаге создания. В Desktop класс берётся из ТУП
(`tup_documents.grade`, см. `src/panels/KtpList.tsx` и `fromDb.ts`).
