## Исправленные баги

1. **Потеря `4.2.2.4` (трудовое обучение)** — в HTML-источнике код записан как `4.2.2.4. декорировать…` (точка сразу после кода). Стандартный `find_objective_codes` отклонял такой код (`*b != b'.'`). Добавлен `find_objective_codes_html`, допускающий точку после кода, если за ней следует описание (не цифра/точка). Заголовки колонок (`7.1.1. 8.1.1.`) по-прежнему отсекаются.

2. **Некорректный `target_grades`** — для заголовков вида «10-11 классов естественно-математического направления» раньше возвращался диапазон «1-12». `extract_target_grades` переписан на регулярные выражения (`для N-M классов`, `для N класса`) → теперь «10-11», «7-9», «1-1» и т.д.

3. **Пустые описания при `<br>`-разделении** — в HTML-ячейках код и описание часто лежат на разных строках, разделённых `<br>`:
   ```
   <td><p>5.1.4.1<br>
   прогнозировать содержание по отрывкам текста</p></td>
   ```
   Построчная обработка теряла описание (например, 91 пустая цель в математике 1-4, 14 в русском 5-9). Исправлено: строки ячейки склеиваются (после отбрасывания строк-заголовков), и цели извлекаются из склеенного текста с границами описаний между соседними кодами.

4. **Голые коды-заголовки колонок** — ячейки вида `<td><p>8.1.3</p></td>` (заголовок колонки матричной таблицы) извлекались как цели с пустым описанием. Такие коды теперь отбрасываются (цель без описания).
