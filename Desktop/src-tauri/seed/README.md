# Базовые данные (Seed Data)

В этой папке хранятся эталонные JSON-файлы с распарсенными Типовыми учебными программами (ТУП) для базы данных. 
Они генерируются из исходных HTML-файлов (расположенных в папке `Materials/`) с помощью скрипта `export_tup_html.rs`.

## Файлы
- `tup_ru.json`: Цели обучения для школ с русским языком обучения.
- `tup_kz.json`: Цели обучения для школ с казахским языком обучения.
- `patch_appendix_numbers.py`: Утилита для точечного обновления номеров Приложений в базе данных без ее полного сброса.

## Как импортировать данные

### Вариант 1: Чистая установка (БД пустая)
Для импорта этих данных в пустую SQLite базу используйте стандартную команду:
```bash
# Находясь в директории src-tauri
cargo run --bin import_tup_html -- --reimport "seed/tup_ru.json" "seed/tup_kz.json" "%APPDATA%/com.teacher.vectorworkspace/vector.db"
```
*(Внимание: Это удалит существующие ТУП. Если в базе уже есть созданные КТП-планы, команда завершится ошибкой `FOREIGN KEY constraint failed`).*

### Вариант 2: Горячее обновление (БД уже используется)
Если у пользователей уже созданы календарно-тематические планы, вы **не можете** пересоздавать документы, иначе сломаются связи с КТП-уроками. Для точечного обновления (например, если обновился алгоритм вычисления номеров приложений, но сами цели не менялись) используйте скрипт:
```bash
python patch_appendix_numbers.py tup_ru.json tup_kz.json "%APPDATA%/com.teacher.vectorworkspace/vector.db"
```
