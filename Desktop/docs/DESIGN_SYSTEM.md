# Design System & UI Guidelines — VectorWorkspace (Tauri + React)

> Архитектурное ТЗ и чеклист для код-ревью каждого нового экрана/компонента.
> Статус: **черновик для оценки**. Пока применяется локально — только на тестовой
> странице `DesignSandbox` (`src/DesignSandbox.tsx`). Глобально стили НЕ подключены.

---

## 1. Архитектура тем и дизайн-токены

- Тема переключается через атрибут `data-theme="light | dark"` на корневом
  элементе (или класс `.dark`, Tailwind-совместимо).
- Все цвета объявляются через CSS-переменные / Tailwind-токены. Никаких
  хардкодных HEX в компонентах.

### Правила работы с цветом

- **Никакого чистого `#000000` в тёмной теме.**
- Элевация (глубина) в тёмной теме строится на яркости фона и границах, а не на тенях:
  - Фоновый слой окна → самый тёмный.
  - Контейнеры/карточки → светлее.
  - Выпадающие списки/модалки → ещё светлее + тонкий бордер.

## 2. Специфика Desktop-приложения (Tauri)

- **Titlebar & кастомный фрейм окна:** верхняя панель управления (Close/Minimize/
  Maximize) гармонирует с темой. Области перемещения окна имеют
  `data-tauri-drag-region`. Все интерактивные элементы внутри драг-зоны обязаны
  иметь явное отключение перетаскивания (`no-drag` / `pointer-events-auto`), чтобы
  клики не перехватывались окном.
- **Скроллбары:** без стандартных белых полос Chromium в тёмной теме. Ширина
  6–8px, радиус 4px, цвет бегунка `--border-strong`, фон прозрачный.
- **Отключение нежелательного поведения браузера:**
  - `user-select: none` для служебного текста (навигация, кнопки).
  - `user-select: text` только для таблиц, кодов целей, описаний и инпутов.
  - Правый клик: кастомное меню или глушение нативного.

## 3. Сетка, отступы и типографика

- **Сетка (4px / 8px):** все отступы (padding/margin/gap) кратны 4 или 8:
  `4, 8, 12, 16, 20, 24, 32`.
- **Плотность Desktop Compact:**
  - Стандартный инпут/кнопка: **36px** (`h-9`).
  - Компактные кнопки/теги: **28–32px** (`h-7`–`h-8`).
  - Строка таблицы: **40–48px**.
- **Скругления:**
  - Теги, бейджи, чипы: **6px** (`rounded`).
  - Инпуты, селекты, кнопки: **8px** (`rounded-lg`).
  - Карточки, модалки, таблицы: **12px** (`rounded-xl`).
  - Аватары/иконки-счётчики: **9999px** (`rounded-full`).
- **Типографика:** Inter, Golos Text или системный Sans-Serif.
- **Табличные цифры (критично для КТП/ТУП):** для дат, номеров уроков, часов,
  процентов и кодов целей (`8.3.1.1`) обязателен `font-variant-numeric: tabular-nums`
  (`tabular-nums` / `font-mono`). Предотвращает смещение колонок.

## 4. Правила проектирования компонентов

### 4.1. Карточки и контейнеры
- Не вкладывать контейнеры бесконечно («белое на белом» с двойными рамками).
- Заголовок секции — снаружи карточки контента, либо в явном `CardHeader` с
  нижней линией разделителя.

### 4.2. Таблицы данных (КТП / ТУП)
- **Sticky Header:** `<thead>` зафиксирован при скролле (`sticky top-0`,
  фон `--bg-surface`, `z-10`).
- **Разделители разделов (четверти, темы):** акцентная полоса слева (3–4px) +
  фон `--bg-subtle`. Визуально разбивают монотонное полотно.
- **Индикаторы прогресса четвертей:** компактные прогресс-бары (4–6px) с
  подписями `1-я: 100%`, `2-я: 100%`, `3-я: 90%`.

### 4.3. Блок валидации расхождения часов (Alert Box)
- **Запрет:** сплошное красное полотно текста на пол-экрана.
- **Правило:** компактный плавающий/встраиваемый Alert-баннер
  (`--status-error-bg`, бордер `--status-error-border`).
- Сводка в 1–2 строки: `⚠️ Не сходится норма: 68 ч. / Фактически: 109 ч. (+41 ч.)`.
- Расхождения по четвертям — компактные бейджи-теги или аккордеон
  («Подробнее по четвертям ▾»): `1-я четв.: +15 ч.`, `2-я четв.: +8 ч.`,
  `3-я четв.: +17 ч.`

### 4.4. Панель поиска и фильтров
- Поиск — одна смысловая строка (без дублирования «Поиск по названию» /
  «Полнотекстовый поиск»).
- Фильтр классов (1–11 кл.) — горизонтальная группа переключателей
  (Segmented Button Group / Chips) с отступом `gap-1.5`.

### 4.5. Кнопки и панель действий (Toolbar)
- **Primary** (1 на экран/секцию): «Сохранить» — акцентный фон, белый текст.
- **Secondary / Outline:** «Авторасчёт дат», «В шаблон», «История» — прозрачный
  фон, бордер `--border-subtle`, текст `--text-primary`.
- **Ghost:** «← К списку», иконки закрытия/удаления.
- **Danger:** «Удалить план», «Сбросить данные».

## 5. Чеклист проверки экрана (Definition of Done для UI)

- [ ] 1. Переключение тем: протестировано в Light и Dark. Ни один текст не стал
      невидимым (белое на белом / тёмное на тёмном).
- [ ] 2. Контрастность: метаданные имеют контраст ≥ 4.5:1 (WCAG AA).
- [ ] 3. Выравнивание чисел: в таблицах КТП/ТУП номера, даты и коды целей
      (`8.3.1.1`) используют `tabular-nums`.
- [ ] 4. Иерархия заголовков: нет дублирования заголовка страницы внутри блоков.
- [ ] 5. Интерактивные состояния: у кнопок, инпутов и строк есть `:hover`,
      `:focus-visible` (кольцо 2px) и `:disabled`.
- [ ] 6. Адаптивность и скролл: при 1024×768 контент не ломается, таблица имеет
      горизонтальный скролл при необходимости, шапка зафиксирована.
- [ ] 7. Компактность ошибок: блоки валидации не сдвигают область на весь экран,
      а отображаются как структурированные алерты.
- [ ] 8. Интеграция с Tauri: в drag-region кнопки и поля остаются кликабельными
      и фокусируемыми.
