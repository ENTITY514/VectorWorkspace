# VectorWorkspace — планы продуктового контура учитель → документ

**Дата:** 2026-09-07  
**Статус:** идеи, оформленные как планы к реализации  
**Область:** КТП, КСП, MCP, данные. Не солвер и не расписание.  
**Связанные документы:** [`../kspEditor/KSP_EDITOR_SPEC.md`](../kspEditor/KSP_EDITOR_SPEC.md), [`../../docs/08-mcp-core.md`](../../docs/08-mcp-core.md), [`../refactor/01_FEATURES_20.md`](../refactor/01_FEATURES_20.md)

Рабочий контур ТУП → КТП → КСП (редактор, каталог, экспорт КСП, MCP с карантином) уже закрыт. Эти восемь планов закрывают следующий слой: учитель видит агента, не теряет данные, сдаёт КТП завучу, возвращается к уроку после звонка.

Каждый план описан единообразно: **Проблема сейчас → Что делаем → Критерий приёмки → Файлы**. Оценка — идеальные дни одного разработчика.

## Порядок исполнения

```
1. Экспорт КТП          → свой шаблон Excel, кнопки в KtpList
2. Резервные копии      → КСП входит в пакет; файл .db по кнопке
3. Чат с агентом        → панель на уроке, diff карантина
4. Рефлексия            → факт проведения кормит саммари
5. Дашборд покрытия     → те же статусы, один экран
6. История версий       → страховка после того, как чат начнут принимать
7. Вложения             → удобство, каталог рядом с копией базы
8. Импорт Excel         → после своего экспорта, иначе вечная борьба с колонками
```

## Чего в этих планах нет

Мультипользователь, облако, Kundelik API, журнал оценок, банк заданий из PDF учебника. Это другой продукт. Пункт меню «Библиотека заданий» остаётся заглушкой, пока не закрыт план 7 и отдельный разбор учебников.
