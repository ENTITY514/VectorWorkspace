# План 7. Вложения к уроку

**Приоритет:** P2  
**Оценка:** 3 дня  
**Зависит от:** [резервные копии](./02_database_backup.md) — иначе файлы не попадают в перенос  
**Не путать с:** пунктом меню «Библиотека заданий» (разбор учебников из PDF)

## Проблема сейчас

«Библиотека заданий» — заглушка: задания из учебников не хранятся. Учитель всё равно держит презентацию, карточки и текст **рядом с темой** — в проводнике, вне КТП/КСП.

В спецификации редактора КСП ресурсы задуманы как список ссылок внутри этапа (учебник, файл, URL). В рабочем КСП отдельной сущности файла на урок нет. MCP не должен таскать сырые байты.

## Что делаем

Вложения висят на уроке КТП (`ktp_lesson_id`) и видны в связанном КСП — один КСП на урок, дублировать файлы не нужно.

- Каталог приложения: `attachments/{lessonId}/{fileId}_{safeName}`.
- В SQLite: `id`, `ktp_lesson_id`, `original_name`, `mime`, `size`, `rel_path`, `note`.
- UI на карточке урока и в просмотрщике КСП: прикрепить (диалог Tauri), открыть, удалить.
- Форматы MVP: pptx, pdf, png, jpg, docx. Лимит размера — константа (например 20 МБ).
- Экспорт Word/PDF КСП — перечень имён в блоке «Ресурсы», не встройка бинарей.
- Агенту — `lesson_list_attachments`: имя, note, mime. Не байты.
- Копия базы без папки `attachments/` помечается неполной; zip-бэкап из плана 2 включает оба.

Не парсить учебники и не строить банк по целям ТУП — это отдельный горизонт библиотеки.

## Критерий приёмки

К уроку прикрепляется PDF, он открывается с карточки КСП. После перезапуска файл на месте. Удаление убирает строку и файл с диска. `lesson_get_bundle` возвращает список вложений. Восстановление только `.db` без папки показывает вложения как «файл не найден», а не падает.
