## 2. Инструкция по загрузке расписания в систему BilimClass

При загрузке утверждённого расписания (V60) в электронный журнал BilimClass необходимо следовать установленным правилам:

### 2.1. Недельная сетка уроков
- **1-я неделя учебного года:** вводятся дни 02–04.09 (дни 31.08 и 01.09 пропускаются).
- **2-я неделя учебного года (и последующие регулярные недели):** вводятся дни 07–11.09 (полная 5-дневная рабочая неделя для всех 19 классов).

Количество уроков по классам для контроля:
- 1А: нед.1 = 11, нед.2 = 18
- 1Б: нед.1 = 12, нед.2 = 20
- 2А: нед.1 = 13, нед.2 = 22
- 2Б: нед.1 = 14, нед.2 = 23
- 3А: нед.1 = 17, нед.2 = 26
- 4А: нед.1 = 15, нед.2 = 25
- 4Б: нед.1 = 16, нед.2 = 27
- 5А: нед.1 = 18, нед.2 = 28
- 5Б: нед.1 = 18, нед.2 = 29
- 6А: нед.1 = 18, нед.2 = 28
- 6Б: нед.1 = 25, нед.2 = 39
- 7А: нед.1 = 20, нед.2 = 33
- 8А: нед.1 = 20, нед.2 = 33
- 8Б: нед.1 = 21, нед.2 = 33
- 8Ә: нед.1 = 19, нед.2 = 32
- 9Б: нед.1 = 24, нед.2 = 41
- 10А: нед.1 = 20, нед.2 = 34
- 11А: нед.1 = 20, нед.2 = 32
- 11Б: нед.1 = 18, нед.2 = 30

### 2.2. Настройка справочников BilimClass
1. **Кабинеты:**
   - В справочник кабинетов добавлены: **№6**, **№8**, **№42** (кабинеты начальных классов).
   - Для физкультуры добавлены: **Малый зал (код 02)** и **Большой зал (код 01)**.
   - Для музыки: **Актовый зал (код 03)**.
2. **Деление на подгруппы:**
   - В настройках предметов активировано деление на 2 подгруппы:
     - Английский язык
     - Казахский язык (в русских классах) / Русский язык (в казахских классах)
     - Информатика
     - Художественный труд (мальчики / девочки)
3. **9Б класс (особый предмет):**
   - Добавлен «Художественный труд» (1 ч/нед, пятница 7-й урок, с делением на мальчиков и девочек).

### 2.3. Соответствие ФИО педагогов
В исходных таблицах и в BilimClass имена сопоставлены следующим образом:
- «Власова А.К.» → в BilimClass привязана как **Дюсембаева А.К.** (смена фамилии).
- «Романишина И.М.» → в BilimClass привязана как **Жукова И.М.**

### 2.4. Исключения (не вводятся в общую сетку)
- Класс **6В (ЛУО)** ведётся по отдельному расписанию (`Materials/Расписание 2026-2027/Расписание_ЛУО_бланк.docx`).
- **Домашнее обучение (ДО):** уроки на дому не ставятся в общие кабинеты (за исключением индивидуально посещаемых уроков инклюзии, учтённых в модели).
- **Факультативы и спецкурсы:** «Личная безопасность», «Закон и Порядок», «Основы Конституции» выставляются вне основного расписания.

## 3. Сборка данных и пайплайн генератора расписания

Если требуется обновить входные данные из BilimClass или пересчитать сетку:

### Этап 1: Преобразование сырых выгрузок в канонический формат
Команды выполняются из корня репозитория:
```bash
# 1. Сборка классов
node tools/bilimclass/build_classes.js

# 2. Сборка учителей и учебных программ
node tools/bilimclass/build_teachers_programs.js

# 3. Сборка базовой нагрузки
node tools/bilimclass/build_curriculum.js

# 4. Внедрение деления на подгруппы
node tools/bilimclass/build_divisions.js

# 5. Сборка списка кабинетов и правил использования
node tools/bilimclass/build_rooms.js
node tools/bilimclass/build_room_rules.js

# 6. Сборка доступности учителей и слотов
node tools/bilimclass/build_availability.js
```

### Этап 2: Решение и оптимизация расписания (CP-SAT Solver)
```bash
# Запуск генератора расписания
python tools/bilimclass/schedule/run_variants.py

# Или прямой запуск через решатель v36
python tools/bilimclass/schedule/solve_v36.py

# Оптимизация распределения кабинетов
python tools/bilimclass/schedule/rooms_opt.py

# Сверка с нормами СанПиН РК
python tools/bilimclass/schedule/compare_sanpin.py
```

### Этап 3: Экспорт результатов в таблицы и бланки
```bash
# Экспорт в Excel (для завуча и BilimClass)
python tools/bilimclass/schedule/export_xlsx.py

# Экспорт бланков Word для печати
python tools/bilimclass/schedule/export_print.py

# Экспорт расписаний ДО и ЛУО
python tools/bilimclass/schedule/export_special_schedules.py
```

## 4. Как продолжить работу на ноутбуке на работе

Чтобы развернуть проект на ноутбуке и продолжить работу:

1. **Склонировать или подтянуть ветку:**
   ```bash
   git fetch origin
   git checkout feat/ksp-editor
   git pull origin feat/ksp-editor
   ```

2. **Необходимое окружение:**
   - **Node.js** (v18+ или v20+)
   - **Python** (3.11 или 3.12) с библиотеками:
     ```bash
     pip install ortools openpyxl python-docx
     ```
   - **Rust / Cargo** (если требуется запускать Desktop/Tauri):
     ```bash
     rustup update stable
     ```

3. **Запуск десктопного приложения (VectorWorkspace):**
   ```bash
   cd Desktop
   npm install
   npm run tauri dev
   ```

4. **Работа с таблицами BilimClass:**
   - Таблицы четвертных оценок открываются в Excel: `bilimclass/Четвертные_оценки_1_четверть_2026_v9.xlsx`.
   - Итоговое расписание: `Materials/Расписание 2026-2027/Расписание_итог..xlsx`.
   - Тестовые данные для алгоритмов: `data/bilimclass/output/` и `data/bilimclass/raw/`.
