## Context

CRUD-вкладки имеют только добавление/удаление без редактирования. Нет подтверждения удаления, нет валидации, нет печати, нет тултипов.

## Goals / Non-Goals

**Goals:**
- Inline-редактирование записей
- Подтверждение удаления
- Валидация ввода с подсветкой ошибок
- Печать расписания
- Тултипы на слотах

**Non-Goals:**
- Drag-and-drop (это отдельная фаза)
- Модальные окна редактирования (inline проще)
- Экспорт в PDF

## Decisions

### D1: Inline edit через toggle state

**Решение:** Каждая запись в списке имеет state `editing: boolean`. При клике — toggle в режим редактирования. Сохранение вызывает API, отмена — сброс.

### D2: Подтверждение через window.confirm

**Решение:** Использовать нативный `window.confirm()` для подтверждения удаления. Просто, работает, не требует дополнительных компонентов.

### D3: Тултипы через CSS title

**Решение:** Использовать нативный `title` атрибут для тултипов. Простой, доступный, не требует библиотек.

## Risks / Trade-offs

- **[Trade-off]** Inline edit vs модальное окно — inline проще, но при много полей может быть неудобно → Приемлемо для 3-5 полей
- **[Risk]** window.confirm выглядит непрофессионально → **Митигация:** Можно заменить на кастомный диалог позже
