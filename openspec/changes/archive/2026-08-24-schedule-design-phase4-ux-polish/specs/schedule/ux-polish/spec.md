## Purpose

UX-полировка модуля «Расписание» — inline-редактирование существующих записей, подтверждение удаления, валидация ввода, печать расписания, тултипы.

## ADDED Requirements

### Requirement: Inline Editing

Система SHALL позволять редактировать существующие записи (учителя/классы/кабинеты/предметы) прямо в списке по клику на запись.

Для учителя: ФИО, макс. уроков/день.
Для класса: класс, буква, смена, кол-во учеников.
Для кабинета: название, тип, вместимость.
Для предмета: id, название, вес, деление.

#### Scenario: Edit teacher inline

- **WHEN** пользователь кликает на учителя в списке — **THEN** запись переходит в режим редактирования (поля ввода вместо текста).

### Requirement: Delete Confirmation

Система SHALL показывать диалог подтверждения перед удалением записи. Диалог SHALL содержать название записи и кнопки «Удалить» / «Отмена».

#### Scenario: Confirm teacher deletion

- **WHEN** пользователь нажимает «Удалить» на учителе — **THEN** появляется диалог «Удалить учителя Иванов И.И.?» с кнопками подтверждения.

### Requirement: Input Validation

Система SHALL валидировать ввод при добавлении/редактировании:

- Учитель: ФИО обязателен, макс. уроков 0..10
- Класс: класс 1..11, буква непустая, ученики 1..50
- Кабинет: название уникально, вместимость 1..200
- Предмет: id непустой, название непустое, вес 1..10

Ошибки SHALL отображаться красным текстом под полем.

#### Scenario: Validation error on empty teacher name

- **WHEN** пользователь пытается сохранить учителя с пустым ФИО — **THEN** поле подсвечивается красным и показывается «ФИО обязателен».

### Requirement: Print Schedule

Система SHALL предоставлять кнопку «Печать» на вкладке «Матрица». При нажатии SHALL открываться print-friendly версия расписания (только таблица, без навигации).

#### Scenario: Print opens clean table

- **WHEN** пользователь нажимает «Печать» — **THEN** открывается окно печати с таблицей расписания.

### Requirement: Slot Tooltips

Система SHALL показывать полную информацию о слоте при наведении на чипс в матрице:

- Класс (полное название)
- Предмет (название)
- Учитель (ФИО)
- Кабинет (название + тип)
- Подгруппа (если есть)

#### Scenario: Tooltip shows full slot info

- **WHEN** пользователь наводит на чипс в матрице — **THEN** появляется тултип с полной информацией.
