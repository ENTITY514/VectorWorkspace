## Purpose

Продвинутая фильтрация расписания — множественные фильтры по дням, классам, предметам, учителям, кабинетам, сменам и подгруппам с быстрыми пресетами и поиском в справочниках.

## ADDED Requirements

### Requirement: Multi-Criteria Grid Filtering

Система SHALL предоставлять панель фильтров-чипсов на вкладке «Матрица» с следующими критериями:

- **День**: выбор одного или нескольких дней недели (Пн–Сб)
- **Класс**: выпадающий список всех классов
- **Предмет**: выпадающий список всех предметов
- **Учитель**: выпадающий список всех учителей
- **Кабинет**: выпадающий список всех кабинетов
- **Смена**: Первая / Вторая / Все
- **Подгруппа**: 1гр / 2гр / Все

Каждый активный фильтр отображается как chip с крестиком для сброса. Сброс всех фильтров — кнопка «Сбросить».

#### Scenario: Filter by day shows only that day

- **WHEN** пользователь выбирает фильтр «Пн» — **THEN** отображаются только слоты с `day===0`.

#### Scenario: Multiple filters combine with AND

- **WHEN** выбраны фильтры «Пн» и «Класс 8А» — **THEN** отображаются только слоты, которые соответствуют ОБОИМ критериям.

#### Scenario: Chip dismiss removes filter

- **WHEN** пользователь нажимает крестик на чипсе «Учитель Иванов» — **THEN** фильтр по учителю сбрасывается.

### Requirement: Quick Filter Presets

Система SHALL предоставлять кнопки-пресеты для типичных сценариев:

- **«Мой день»**: показать только текущий день недели
- **«Первая смена»**: показать только слоты классов первой смены
- **«Вторая смена»**: показать только слоты классов второй смены
- **«Без окон»**: показать только слоты без окон (смежные уроки)

#### Scenario: My day preset

- **WHEN** сегодня вторник и пользователь нажимает «Мой день» — **THEN** отображаются только слоты с `day===1`.

#### Scenario: Without windows preset

- **WHEN** пользователь нажимает «Без окон» — **THEN** отображаются только слоты, где у учителя нет окон между уроками.

### Requirement: Search in Reference Lists

Система SHALL предоставлять строку поиска в CRUD-вкладках (Учителя, Классы, Кабинеты, Предметы) при количестве записей > 5.

Поиск SHALL фильтровать список по частичному совпадению с name/full_name/id.

#### Scenario: Teacher search filters list

- **WHEN** в списке учителей 20 записей и пользователь вводит «Пет» — **THEN** отображаются только учителя, чьё ФИО содержит «Пет».
