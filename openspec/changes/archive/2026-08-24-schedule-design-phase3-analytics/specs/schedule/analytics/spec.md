## Purpose

Аналитика расписания — детализация метрик штрафов, сравнение legacy vs CP-SAT, экспорт отчётов, аналитика по учителям и классам.

## ADDED Requirements

### Requirement: Detailed Metrics Comparison

Система SHALL отображать таблицу-сравнение legacy vs наше расписание по каждой метрике:

- Окна (штраф)
- СанПиН-парабола (штраф)
- Чередование (штраф)
- Баланс нагрузки (штраф)
- Замещение кабинета (штраф)
- Миграция (штраф)
- Общий взвешенный штраф

Каждая строка SHALL содержать: значение legacy, значение наше, дельта, % улучшения.

#### Scenario: Metrics table shows per-metric comparison

- **WHEN** пользователь открывает вкладку «Сравнение» — **THEN** таблица показывает 7 метрик с legacy/наше/дельта/%.

### Requirement: Real Benchmark Data Loading

Система SHALL загружать данные из `data/synthetic/benchmark_summary.json` при открытии вкладки «Сравнение». Если файл недоступен — показывать заглушку.

#### Scenario: Benchmark data loaded from file

- **WHEN** файл `benchmark_summary.json` доступен — **THEN** данные отображаются в таблице.

### Requirement: Post-Generation Summary

Система SHALL показывать сводку после генерации на вкладке «Сводка»:

- Количество окон у учителей
- Максимальная нагрузка на класс/учителя
- Статус (Оптимально/Решаемо/Невозможно)
- Время решения
- Общий штраф

#### Scenario: Summary shows after generate

- **WHEN** генерация завершена успешно — **THEN** на вкладке «Сводка» отображается карточка «Результат генерации» с метриками.

### Requirement: Export Schedule

Система SHALL предоставлять кнопку «Экспорт CSV/JSON» для текущего расписания. Экспорт SHALL включать все слоты с полями: класс, предмет, учитель, кабинет, день, период, подгруппа.

#### Scenario: Export CSV downloads file

- **WHEN** пользователь нажимает «Экспорт CSV» — **THEN** скачивается файл `.csv` со всеми слотами.

### Requirement: Teacher Analytics

Система SHALL отображать аналитику по учителю при выборе из списка:

- Количество уроков в неделю
- Количество уроков по дням (Пн–Сб)
- Наличие окон
- Список классов

#### Scenario: Teacher analytics shows load distribution

- **WHEN** пользователь выбирает учителя — **THEN** отображается распределение уроков по дням и информация об окнах.

### Requirement: Class Analytics

Система SHALL отображать аналитику по классу при выборе из списка:

- Количество уроков в неделю
- Количество уроков по дням
- Количество двойных уроков
- Список предметов и учителей

#### Scenario: Class analytics shows subject distribution

- **WHEN** пользователь выбирает класс — **THEN** отображается распределение предметов по дням и список учителей.
