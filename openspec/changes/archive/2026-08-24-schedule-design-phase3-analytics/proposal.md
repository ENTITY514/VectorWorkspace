## Why

Текущий раздел «Сравнение» содержит хардкод данных из предыдущего запуска. Педагог не видит детализацию по метрикам (окна, СанПиН, чередование), не может сравнить расписание по кварталам, не видит статистику после генерации. Нет экспорта отчёта.

## What Changes

- **Загрузка реальных данных бенчмарка** из `benchmark_summary.json` вместо хардкода
- **Детализация по метрикам**: таблица-сравнение legacy vs наше по каждой метрике с дельтой и % улучшения
- **Сводка после генерации**: кол-во окон, отклонение от СанПиН, макс. нагрузка, время решения
- **Сравнение по кварталам**: таблица улучшений от квартала к кварталу
- **Экспорт отчёта**: кнопка «Экспорт CSV/JSON» для текущего расписания
- **Аналитика по учителю**: при выборе — сколько уроков/день, есть ли окна
- **Аналитика по классу**: распределение по дням, кол-во двойных уроков

### New Capabilities
- `schedule/analytics`: Аналитика расписания — детализация метрик, сравнение, экспорт, аналитика по учителям/классам
