## Purpose

Определяет поведение верхней обвязки приложения (app chrome) для десктоп-клиента VectorWorkspace на Tauri + React: нативный заголовок окна, сворачиваемый сайдбар, заголовок раздела, переключатель темы и меню пользователя.

## ADDED Requirements

### Requirement: Кнопки управления окном работают в Tauri и скрыты вне него
Система MUST показывать кнопки управления окном (свернуть, развернуть, закрыть) только при запуске внутри рантайма Tauri, и MUST вызывать нативные API окна (`@tauri-apps/api/window`) для их функционирования. Вне рантайма Tauri (обычный браузер) эти кнопки MUST быть скрыты, чтобы не создавать неработающих («мёртвых») элементов.

#### Scenario: Запуск внутри Tauri
- **WHEN** приложение запущено в рантайме Tauri
- **THEN** отображаются кнопки свернуть/развернуть/закрыть, и нажатие на каждую выполняет соответствующее нативное действие с окном

#### Scenario: Запуск в обычном браузере
- **WHEN** приложение открыто в браузере без рантайма Tauri
- **THEN** кнопки управления окном скрыты, а заголовок окна остаётся перетаскиваемым

### Requirement: Сворачиваемый минималистичный сайдбар
Система MUST позволять сворачивать боковую панель навигации в минималистичный вид (только иконки) и разворачивать обратно. Состояние свёрнутости MUST сохраняться между перезагрузками.

#### Scenario: Сворачивание сайдбара
- **WHEN** пользователь нажимает кнопку сворачивания в заголовке
- **THEN** сайдбар сужается до узкой колонки, подписи пунктов/бренд/подвал скрываются (остаются только иконки с подсказками)

#### Scenario: Сохранение состояния
- **WHEN** пользователь перезагружает приложение
- **THEN** сайдбар отображается в том же состоянии (свёрнут/развёрнут), что было до перезагрузки

### Requirement: Заголовок приложения с переключателем темы
Система MUST отображать в заголовке название текущего раздела и его подзаголовок, а также MUST предоставлять переключатель темы (только иконками, без текстовых подписей), меняющий тему Light/Dark.

#### Scenario: Переключение темы
- **WHEN** пользователь нажимает иконку переключателя темы
- **THEN** тема приложения переключается между Light и Dark и применяется немедленно

### Requirement: Меню пользователя с расширяемым набором пунктов
Система MUST предоставлять кнопку-аватар, открывающую выпадающее меню пользователя. Состав пунктов меню MUST задаваться конфигурационным массивом, чтобы новые действия (профиль, настройки, вход, выход и др.) можно было быстро добавлять и связывать. Меню MUST закрываться по клику вне его или по Escape.

#### Scenario: Базовый состав и навигация
- **WHEN** пользователь открывает меню пользователя
- **THEN** отображаются пункты (как минимум Профиль, Настройки, Вход, Выход), и выбор «Настройки» перенаправляет на экран настроек

#### Scenario: Закрытие меню
- **WHEN** меню открыто и пользователь кликает вне меню или нажимает Escape
- **THEN** меню закрывается
