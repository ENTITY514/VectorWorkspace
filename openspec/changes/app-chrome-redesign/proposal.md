## Why

После внедрения кастомного фрейма окна (Tauri titlebar) пользователь сообщил, что кнопки верхней панели «вообще перестали работать». Причина: кнопки управления окном (свернуть/развернуть/закрыть) вызывают `@tauri-apps/api/window`, который недоступен вне рантайма Tauri (например, при запуске Vite-dev в обычном браузере) — обработчик молча завершается no-op, и кнопки выглядят «мёртвыми».

Одновременно требуется улучшить «обвязку» приложения (app chrome):
- сворачиваемый в минималистичный (только иконки) вид сайдбар;
- отдельный заголовок приложения (header) с перенесённым названием, переключателем темы (только иконками) и меню пользователя (аватар) с расширяемым набором пунктов (профиль, настройки, вход, выход).

## What Changes

- **Исправление кнопок окна**: кнопки управления окном рендерятся только внутри рантайма Tauri и корректно вызывают нативные API; вне Tauri они скрываются, чтобы не создавать «мёртвых» кнопок.
- **Сворачиваемый сайдбар**: состояние `collapsed` управляется на уровне `MainLayout`, сохраняется в `localStorage`; в свёрнутом виде сайдбар показывает только иконки (узкая колонка, скрыты подписи/бренд/подвал).
- **Заголовок приложения (AppHeader)**: переносит название текущего раздела из `page-head`; содержит иконочный переключатель темы (☀/☾) и кнопку-аватар меню пользователя.
- **Меню пользователя (UserMenu)**: выпадающий список, формируемый из конфигурационного массива пунктов (`UserMenuItem[]`) для быстрого добавления/связывания новых действий; пункт «Настройки» уже связывается с переходом на экран настроек.

## Capabilities

### New Capabilities
- `app-chrome`: Требования к верхней обвязке приложения — оконный заголовок (Tauri), сворачиваемый сайдбар, заголовок раздела, переключатель темы и меню пользователя.

### Modified Capabilities
- (нет — новая возможность)

## Impact

- `Desktop/src/shared/ui/layout/Titlebar.tsx`: детекция Tauri, условный рендеринг контролов окна.
- `Desktop/src/shared/ui/layout/Sidebar.tsx`: поддержка `collapsed` (иконочный минималистичный вид).
- `Desktop/src/shared/ui/layout/MainLayout.tsx`: состояние `collapsed`, рендер `AppHeader` вместо `page-head`.
- `Desktop/src/shared/ui/layout/AppHeader.tsx`: новый компонент (заголовок + переключатель темы + UserMenu).
- `Desktop/src/shared/ui/layout/UserMenu.tsx`: новый компонент (аватар + выпадающее меню по конфигу).
- `Desktop/src/shared/ui/layout/useTheme.ts` (или существующий хук темы): переиспользуется для иконочного переключателя.
- `Desktop/src/styles.css`: стили `.app-header`, `.sidebar.collapsed`, `.user-menu`, аватара.
