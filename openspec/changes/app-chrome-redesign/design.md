## Context

Текущая обвязка (`MainLayout`) содержит кастомный Tauri-заголовок (`Titlebar`) и сайдбар с `page-head` внутри `.main`. После включения `decorations: false` в `tauri.conf.json` кнопки управления окном перестали работать вне Tauri (рантайм недоступен → no-op). Нет сворачивания сайдбара, нет выделенного заголовка с переключателем темы и меню пользователя.

Тема уже управляется хуком `useTheme` (устанавливает `data-theme` на `<html>` и сохраняет выбор в `localStorage` под ключом `vw-theme`). Этот хук переиспользуется для иконочного переключателя в заголовке.

## Goals / Non-Goals

**Goals:**
- Устранить «мёртвые» кнопки окна: рендерить их только в Tauri и корректно вызывать нативные API.
- Добавить сворачиваемый сайдбар (icon-only) с сохранением состояния.
- Вынести название раздела в отдельный `AppHeader` с иконочным переключателем темы и `UserMenu`.
- Сделать `UserMenu` расширяемым через конфигурационный массив пунктов.

**Non-Goals:**
- Реализация логики профиля/входа/выхода (пока заглушки; связывается «Настройки»).
- Изменение существующего экрана `Settings` (только навигация к нему).
- Смена нативных `decorations` окна (оставляем `false`).

## Decisions

- **Детекция Tauri**: проверка `"__TAURI_INTERNALS__" in window`. Контролы окна рендерятся только при `true`.
- **Разделение drag-region и контролов**: кнопки окна остаются сиблингами элемента с `data-tauri-drag-region` (не потомками), чтобы Tauri не перехватывал их клики для перетаскивания.
- **Права доступа Tauri v2**: вызовы `getCurrentWindow().minimize()/toggleMaximize()/close()` и перетаскивание через `data-tauri-drag-region` требуют явных разрешений в capability-файле (`core:window:allow-*`). Без них Tauri v2 отклоняет вызовы, и из-за `try/catch` в `windowAction` кнопки выглядели «мёртвыми». Разрешения добавлены в `src-tauri/capabilities/default.json`.
- **Состояние сворачивания**: поднимается в `MainLayout` (`useState` + `localStorage["vw-sidebar-collapsed"]`), передаётся в `Sidebar` через проп `collapsed`. Переключатель вынесен в бренд сайдбара (`.sidebar-brand` — кликабельная кнопка) с анимированным шевроном: развернутый вид — стрелка влево (свернуть), свёрнутый — стрелка вправо (развернуть, `rotate(180deg)` + `transition`), подпись плавно сворачивается (`max-width`/`opacity`). Дублирующий «гамбургер» из `AppHeader` убран.
- **AppHeader заменяет `page-head`**: название/подзаголовок раздела берутся из существующих карт `titles`/`subtitles` в `MainLayout`. Справа: иконочный переключатель темы (☀/☾) и `UserMenu`.
- **UserMenu по конфигу**: тип `UserMenuItem = { id; label; icon?; onSelect: () => void }`. Базовый массив: Профиль (заглушка), Настройки (`onSelect` → `onNavigate("settings")`), Вход (заглушка), Выход (заглушка). Закрытие по `mousedown` вне/`Escape` через `useEffect` + `ref`.
- **Токены**: все новые стили используют переменные Design System (`--bg-surface`, `--bg-subtle`, `--border-subtle`, `--border-strong`, `--text-*`, `--accent-*`, радиусы `--radius-sm`/`--radius-lg`, `focus-visible` кольцо 2px).

## Risks / Trade-offs

- [Risk] Две верхние полосы (OS-titlebar + AppHeader) визуально утяжеляют интерфейс.
  - Mitigation: AppHeader делаем компактным (h~52px), без лишних границ; OS-titlebar — узким (38px).
- [Risk] В свёрнутом сайдбаре иконки без подписей снижают понятность.
  - Mitigation: `title`-атрибуты на иконках-кнопках для подсказок.
- [Risk] В браузере контролы окна скрыты — управление окном недоступно.
  - Mitigation: это ожидаемо вне Tauri; в продакшене (Tauri) контролы работают.
