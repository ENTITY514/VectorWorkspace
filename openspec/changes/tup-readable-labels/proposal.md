## Why

На странице ТУП карточки документов и элементы фильтров показывают внутренние технические/английские значения: `common`, `RU`, `KZ`, `objective`, `section`, `topic`, `task`, сокращения `Прил.`, `ДСП`, `FTS5`. Для учителя (целевая аудитория) эти слова непонятны. Нужно заменить их на осмысленные русские подписи, сохранив единый источник истинности для всех экранов ТУП.

## What Changes

- Введён общий модуль подписей `src/domains/tup/labels.ts` (направление, язык, тип сущности FTS), чтобы текст отображался одинаково в карточках, фильтрах, детали документа и результатах полнотекстового поиска.
- Поле `directionStr` документа ТУП теперь содержит человекочитаемую подпись (`Общеобразовательная` / `ЕМН` / `ОГН`) вместо `common`/`emn`/`ogn`.
- Язык обучения отображается как `Русский` / `Казахский` вместо `RU` / `KZ`.
- Типы сущностей FTS (`objective`/`section`/`topic`/`task`) — как `Цель` / `Раздел` / `Тема` / `Задание`.
- Сокращения уточнены: `Прил.` → `Приложение`; `ДСП` снабжён подсказкой; техническое `FTS5` убрано из подсказки поиска.

## Capabilities

### New Capabilities
- `tup-readable-labels`: Человекочитаемые подписи вместо технических/английских значений на всех экранах ТУП.

### Modified Capabilities
- (нет)

## Impact

- `Desktop/src/domains/tup/labels.ts`: новый модуль с `directionLabel`, `directionFull`, `languageLabel`, `entityTypeLabel`.
- `Desktop/src/services/api.ts`: `directionStr` формируется через `directionLabel`.
- `Desktop/src/domains/tup/useTupList.ts`: направления для фильтра собираются без исключения `common`.
- `Desktop/src/domains/tup/ui/TupDocumentCard.tsx`: бейджи направления/языка, `Прил.`→`Приложение`, подсказка `ДСП`.
- `Desktop/src/domains/tup/ui/TupDetail.tsx`: подписи направления (с tooltip) и языка.
- `Desktop/src/domains/tup/ui/TupList.tsx`: опции фильтров направления/языка, мета FTS, бейдж типа сущности, подсказка поиска.
