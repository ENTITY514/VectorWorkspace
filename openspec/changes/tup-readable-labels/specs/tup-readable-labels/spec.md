## Purpose

Гарантирует, что на всех экранах ТУП (типовые учебные программы) вместо внутренних технических и английских значений отображаются понятные учителю русские подписи.

## ADDED Requirements

### Requirement: Человекочитаемые подписи направления и языка ТУП
Система MUST отображать направление документа ТУП и язык обучения человеческим языком: `common` → «Общеобразовательная», `emn` → «ЕМН» (естественно-математическое направление), `ogn` → «ОГН» (общественно-гуманитарное направление); `ru` → «Русский», `kz`/`kk` → «Казахский». Сырые английские/кодовые значения (`common`, `RU`, `KZ`) MUST быть скрыты от пользователя.

#### Scenario: Карточка документа ТУП
- **WHEN** пользователь видит карточку документа ТУП общеобразовательного направления на русском языке
- **THEN** на карточке показаны подписи «Общеобразовательная» и «Русский» (без `common`/`RU`)

#### Scenario: Фильтр направления/языка
- **WHEN** пользователь открывает выпадающие фильтры на странице ТУП
- **THEN** опции содержат понятные подписи («ЕМН», «ОГН», «Общеобразовательная», «Русский», «Казахский»), а не сырые коды

### Requirement: Человекочитаемые типы сущностей в результатах поиска
Система MUST отображать тип сущности в результатах полнотекстового поиска по-русски: `objective` → «Цель», `section` → «Раздел», `topic` → «Тема», `task` → «Задание».

#### Scenario: Результаты FTS
- **WHEN** пользователь видит найденный фрагмент в полнотекстовом поиске
- **THEN** бейдж типа сущности показывает русскую подпись, а не английское слово

### Requirement: Понятные сокращения
Система MUST заменять неочевидные сокращения понятными формулировками: «Прил.» → «Приложение»; «ДСП» снабжать поясняющей подсказкой; техническое обозначение `FTS5` не выводить в пользовательском интерфейсе.

#### Scenario: Карточка документа
- **WHEN** пользователь читает мета-информацию карточки
- **THEN** вместо «Прил. 3» показано «Приложение 3», а бейдж «ДСП» имеет подсказку с расшифровкой
