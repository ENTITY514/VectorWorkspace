# Design: Версии, сравнение, отчёты по ролям

## Статусы версий

```
Черновик ──► Кандидат ──► На просмотре ──► Утверждена ──► Архив
    ▲             │              │               │
    └─────────────┴── вернуть ───┘       (при утверждении новой — прежняя → Архив)
```

- `Утверждена` — не больше одной на учебный год/четверть; совпадает с `is_active`.
- `На просмотре`: при переводе указываются адресаты («группа завучей») и дата; выгрузка помечается «На просмотре».
- «Почистить черновики»: список черновиков и пробных вариантов старше N дней → архив/удаление (удаление подтверждается;
  данные можно пересобрать, если вариант — дочерний и есть снимок).
- В списке версий: статус, база, вид (`generated`/`min_moves`/…), ключевые метрики, дата.

## Сравнение версий

### Итог

```
┌ V53 ⇄ V36 ─────────────────────────────────────────────────────────────┐
│ Совпадают по времени 431 / 519 (83 %) · в тот же день 462 (89 %)        │
│ Началка 1–4: 100 %  · 7А 44 %  · 8Б 55 %  · 11Б 67 % …                  │
│ Учителя без изменений: 12 из 37                                         │
├───────────────┬──────────┬──────────┬─────────────────────────────────┤
│ Метрика       │   V36    │   V53    │                                  │
│ СанПиН        │  1169    │  1139 ▼  │                                  │
│ Окна учителей │    95    │    82 ▼  │                                  │
│ …             │          │          │                                  │
└───────────────┴──────────┴──────────┴─────────────────────────────────┘
```

- Совпадение считается с учётом взаимозаменяемых одинаковых уроков (мультимножество слотов в группе).
- Метрики — `solver/metrics.py`; версии, нарушающие жёсткие правила, помечаются (в кейсе V36 имела запрещённую
  геометрию; метрика СанПиН для неё считается с пометкой).
- Режим «несколько версий»: колонки V33 / V36 / V53.

### Различия по людям

Вкладки «Учителя» / «Классы»: для каждого — было/стало (неделя), окна, поздние старты, дни ради одного урока,
обмены; сортировка «кому хуже всего». Клик — отчёт по роли с режимом сравнения.

## Отчёты по ролям

| Отчёт | Содержимое |
|---|---|
| **Учитель** | неделя (урок, класс, кабинет, время звонка), окна (обычные и с 1-го урока, если классный руководитель), сдвоенные окна, время прихода/ухода по дням, дни ради одного урока, обмены кабинетами (с кем, когда), окна с английским под обмен (для владельца кабинета), сравнение с базой |
| **Классные руководители** | таблица: учитель, класс, часы, окна обычные и с 1-го урока, во сколько приходит на уроки по дням; сравнение с базой |
| **Класс («глазами ребёнка»)** | нагрузка по дням против кривой (баллы), трудные на 6–7 уроке, трудный последним уроком, 3 трудных подряд, 3 языка в день, 7-е уроки, чередование пар (устранимые и неизбежные), физкультура — какой зал |
| **Ученик на инклюзии** | маршрут по дням: урок, предмет, ✔ ходит / — не ходит, окна, приход/уход по времени; какие N из M уроков выбраны |
| **Завуч** | проверка требований, накладки (реальные / совместные уроки), совместители (дни, окна), залы, обмены кабинетами, правки завуча и их статус, пожелания учителей |
| **Администрация** | дни и уроки администрации, свободные дни |

Все отчёты: экспорт xlsx/pdf; режим «сравнить с …».

## Проверка требований (аудит)

- Источник — профиль школы и обязательные правила каталога; для каждого требования проверка **по каждой сущности
  и дню** независимым кодом (`solver/audit.py`), без использования переменных модели.
- Статусы: ✅ выполнено, ⚠ выполнено с исключением (пожелание, явное решение школы), ❌ не выполнено.
- Доказательство — конкретные строки: «Анастасия, 7А: Пн 1 — алгебра ✔, последний урок 2; Вт 1 — казахский ✔ …».
- Аудит запускается автоматически после каждого расчёта и при переводе версии в «На просмотре» (перевод блокируется
  при ❌ в обязательных требованиях, с возможностью явного подтверждения).

## Накладки и совместные уроки

- `schedule_collisions`: учитель/класс/кабинет в двух местах одновременно, пересечения с ДО по реальному времени
  звонков (время ДО может не совпадать со звонками).
- Совместный урок класс-комплекта (одна встреча, несколько классов) — не накладка; показывается отдельным списком
  «совместные уроки (показаны в колонке каждого класса)».
- Выгрузка: в ячейке совместного урока — «вместе с 6В» / «вместе с 2А, 4А»; в листе «Учителя» совместный урок
  показывается один раз с перечнем классов.

## Выгрузка

- Статус и номер версии в шапке и имени файла; бланки ЛУО/ДО — с номером версии (сейчас перезаписываются без номера).
- Необязательный лист «Изменения относительно утверждённой версии»: список сдвигов с причинами (закрепления,
  правки завуча, требования).
