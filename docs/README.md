## Ключевые артефакты системы

- **Форм-фактор:** локальное десктоп-приложение (Tauri v2 + Rust Core + React/TS)
- **Хранение:** Offline-First, SQLite (WAL); облако (PostgreSQL/Supabase) — синхронизация и библиотека учебников
- **Инварианты:** зашиты в типы Rust, валидаторы и триггеры БД
- **AI:** только Markdown/LaTeX через MCP-инструменты, вывод моделей в RAM-карантине

## Соглашения

- Код цели обучения: `[Класс].[Раздел].[Подраздел].[Номер]`, например `7.2.1.2`, `8.4.1.3`.
- Валидаторы хронометража: `Σ DurationStage = 45 мин` (КСП).
- Инварианты КТП: `Index(Soch) - Index(Last_Sor) = 2`, буфер `TotalLessons_quarter - Index_Soch >= HoursPerWeek`.
- Все изменения данных проходят через MCP Tool Registry и Staging Quarantine перед коммитом в SQLite (WAL).
