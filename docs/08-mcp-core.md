## Модуль 1: Transport Layer
- **StdioTransport** — для OpenCode CLI (локальные агенты, JSON-RPC 2.0 по stdio).
- **HttpSseTransport** — для удалённых API-провайдеров.
- Протокол: JSON-RPC 2.0.

## Модуль 2: Tool Registry & Strict Schemas
- Автогенерация JSON Schema через **schemars** (`schema_for!(Params)`).
- Ключевые инструменты: `read_tup`, `draft_ktp`, `draft_ksp`, `fetch_textbook_exercises`, `fetch_theory`, `get_exercise_by_number`.
- **2-барьерный Execution Guard**: 1-й барьер — валидация схемы входа; 2-й барьер — инварианты результата.

## Модуль 3: Context Reducer & Token Minimizer
- **3-Point Lesson Slicing**: при работе с уроком L_k в контекст подаются только L_(k-1), L_k, L_(k+1) — соседние уроки, а не весь план.
- **Dense Markdown DTO**: сжатые представления документов (сокращённая теория, чистый Markdown/LaTeX).
- Задача — минимизировать токены без потери методического смысла.

## Модуль 4: Hybrid Provider Gateway
- **Провайдеры**: облачный DeepSeek vs локальный OpenCode CLI.
- **Circuit Breaker**: CLOSED → OPEN → HALF-OPEN — при падении одного провайдера происходит переключение на запасной.
- **Fallback Engine**: автоматический фолбэк между провайдерами.
- **OS Keyring**: безопасное хранение API-ключей (системная связка, не в файлах).

## Модуль 5: Staging Quarantine & Verification Guard
1. **Зона изоляции**: `StagedArtifact<T>` в оперативной памяти — артефакт модели не имеет первичного ключа БД.
2. **Гильотина логики** (`InvariantGuillotine`): проверка суммы этапов = 45 мин, весов СОЧ, баллов СОР, инвариантов КТП.
3. **Feedback Loop**: при нарушении правил автоматически генерируется «карательный» промпт с указанием конкретных нарушений, и модель пересобирает артефакт.
4. **Печать разума (User-in-the-Loop)**: визуальный дифф в React UI — пользователь видит изменения перед сохранением.
5. **Атомарная транзакция**: коммит только валидированных данных в локальную SQLite (WAL Mode).

## Zero-Trust принципы
- Модель оперирует только Markdown/LaTeX через MCP-инструменты.
- Модель не имеет прямого доступа к БД и сканам.
- Ничего не пишется в БД без прохождения Quarantine + подтверждения пользователя.
