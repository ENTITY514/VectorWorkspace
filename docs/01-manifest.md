# 01. Паспорт проекта и архитектурный манифест

## Паспорт

| Параметр | Значение |
|----------|----------|
| Наименование продукта | **Vector** — АРМ учителя и методиста |
| Форм-фактор | Локальное настольное приложение (Tauri v2 + Rust Core + React/TypeScript) |
| Модель хранения данных | **Offline-First**: рабочий контур автономен на SQLite (WAL); облако (PostgreSQL/Supabase) — фоновая синхронизация, распространение оцифрованных учебников, сообщество |
| Документ | Генеральная спецификация v1.1 (мастер-спецификация) |
| Статус | Утверждено к реализации |

## Фундаментальные архитектурные принципы

### 1. Code-Enforced Pedagogical Invariants
Требования нормативных регламентов (**Приказ № 130, ГОСО, ТУП**) закодированы в:
- системе типов Rust (newtype-обёртки, запрещённые состояния),
- валидаторах (хронометраж, веса, баллы),
- триггерах базы данных (CHECK-ограничения, computed columns).

Система физически не позволяет сохранить документ, нарушающий методические правила.

### 2. Asymmetric Ingestion Doctrine (асимметрия вычислений)
Тяжёлое распознавание (OCR сложной математики и вёрстки учебников) вынесено на **централизованный этап оцифровки** (сервер разработчика). Пользовательские слабые машины получают:
- готовые лёгковесные структуры SQLite (FTS5),
- только CPU-bound утилиты: **Tesseract** / прямой парсинг PDF (10–20 мс).

### 3. Zero-Trust AI & Schema-Driven Quarantine
- Текстовые AI-модели (DeepSeek Flash / OpenCode) оперируют **только чистым Markdown/LaTeX** через MCP-инструменты.
- Вывод моделей изолируется в **RAM-буфере** (StagedArtifact) и проходит программную «гильотину инвариантов» перед записью в БД.
- Пользователь (User-in-the-Loop) видит дифф и подтверждает перед коммитом.

### 4. Non-Blocking Actor Core
Все I/O-операции, фоновое чтение документов и работа агентов — в асинхронных задачах **tokio**, без блокировки интерфейса Tauri.

## Правила безопасности данных
- AI-модели не получают сырые сканы страниц и не пишут в БД напрямую.
- Доступ к учебникам — только через MCP-инструменты (`fetch_theory`, `fetch_exercises`, `get_exercise_by_number`).
- Коммит — только валидированных артефактов, атомарная транзакция в SQLite (WAL).
