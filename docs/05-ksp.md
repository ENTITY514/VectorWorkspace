# 05. Методический контур: КСП (Поурочные планы, Приказ № 130)

## Обзор

Краткосрочный (поурочный) план формируется на базе урока КТП по форме Приказа МОН РК № 130.

## Требования

### FR-3.1. Связность с КТП
Тема и цели обучения **наследуются автоматически** из выбранного урока КТП — ручной ввод дублирующих данных не допускается.

### FR-3.2. Воспитательный компонент
Обязательное поле `traditional_values` — национальные и общечеловеческие ценности:
трудолюбие, честность, взаимоуважение и т.п.

### FR-3.3. Инвариант хронометража
Сумма минут этапов урока строго равна 45:

```
Σ DurationStage(i) = 45 мин   (i = 1..n)
```

### FR-3.4. Гибридное хранение
Реляционная обвязка (FK на урок КТП, статус, метаданные) + **валидированное тело урока** в столбце JSONB.

## Схема данных

```sql
CREATE TABLE ksp_documents (
    id TEXT PRIMARY KEY,
    ktp_lesson_id TEXT NOT NULL UNIQUE REFERENCES ktp_lessons(id) ON DELETE RESTRICT,
    teacher_id TEXT NOT NULL,
    is_approved INTEGER NOT NULL DEFAULT 0,
    content TEXT NOT NULL,            -- JSONB-структура KspContent
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```

## Структура `KspContent` (JSONB)

Минимальный обязательный набор полей (по Приказу № 130):
- тема урока (наследуется из КТП);
- цели обучения в соответствии с учебной программой;
- цели урока (smart-декомпозиция);
- воспитательный компонент `traditional_values`;
- этапы урока: массив `[{ stage, duration_minutes, teacher_actions, student_actions, assessment, resources }]`;
- связь с СОР (если применимо).

## Валидация (InvariantGuillotine)
1. `Σ duration_minutes == 45` — иначе артефакт отклоняется.
2. `traditional_values` не пуст.
3. Тема/цели совпадают с уроком КТП.
4. Ресурсы/оценивание заполнены для каждого этапа.

## Особенности
- `ktp_lesson_id` — `UNIQUE`: один урок КТП = один КСП.
- `ON DELETE RESTRICT`: нельзя удалить урок КТП с существующим КСП.
- Тело урока редактируется только через MCP Staging Quarantine + User-in-the-Loop дифф перед коммитом.
