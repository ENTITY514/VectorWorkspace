# Набор оценки помощника «текст → команда»

Источник — реальные фразы педагога при доработке расписания 2026–2027 (V33 → V53), дополненные перефразировками.
Используется стендом `ai-eval` слоя намерений AI Core (см. `openspec/changes/ai-core-intent-layer`) как набор домена `schedule` (см. `openspec/changes/schedule-assistant`).

- `commands.jsonl` — фраза → ожидаемые команды реестра с параметрами (`context` — что было до фразы или кто говорит;
  `clarify` — ожидается уточняющий вопрос; `out_of_scope` — вне области).
- `explanations.jsonl` — структурированный результат инструмента → факты, которые обязаны быть в объяснении
  (`must_mention`) и которых быть не должно (`must_not`).
- `results/` — отчёты прогонов провайдеров (метрики и пороги — в `openspec/changes/ai-core-intent-layer/design.md`, раздел 9).

Правила пополнения:
1. Каждая исправленная пользователем карточка «Понял так» (из журнала, после обезличивания) — кандидат в набор.
2. На каждую команду — не меньше 3 фраз, в т. ч. разговорные и с опечатками; на каждую неоднозначность — пример с `clarify`.
3. Казахские фразы (`lang: kk`) сейчас черновые — перед использованием проверить носителем языка.
4. Имена в наборе — из тестовой школы; при передаче наружу заменять метками.
