## Потоки данных

1. **Нормативный базис** → **КТП**: ТУП декомпозируется на четверти/разделы/подразделы/цели; КТП генерируется из ТУП с проставлением типов уроков.
2. **КТП** → **КСП**: тема и цели обучения наследуются из выбранного урока КТП.
3. **КТП** → **СОР/СОЧ**: контрольные точки встраиваются в план с соблюдением инвариантов.
4. **База знаний** ↔ **КТП/КСП**: задачи учебника маппятся на цели ТУП и используются на этапе «Практика».
5. **MCP Core** обслуживает все контуры: чтение ТУП, черновики КСП, выборку заданий, валидацию и коммит.
